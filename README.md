# Finding Frankie - Escape Room Game

A simple web-based escape room game built with Vite and vanilla JavaScript.

## About the Game

In "Finding Frankie," you play as someone who wakes up in a mysterious room. Your friend Frankie has disappeared, and you need to solve puzzles to find clues about their whereabouts.

### Current Features
- Interactive puzzle-solving gameplay
- Code lock puzzle (guess the number based on clues)
- Progress tracking
- Responsive design with dark theme
- Smooth animations and feedback

## Getting Started

### Prerequisites
- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open your browser and navigate to the URL shown in the terminal (typically `http://localhost:5173`)

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build

## How to Play

1. Read the story and clues carefully
2. Solve the puzzle by entering the correct code
3. Progress through the game to find Frankie!

**Hint for Puzzle 1:** Count the letters in "Frankie"
